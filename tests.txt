Тесты для приложения mathtools.py
Решение квадратного уравнения A*x^2 + B*x + C = 0

=====================================================================
1. ТЕСТЫ КОЭФФИЦИЕНТОВ
=====================================================================
Запуск: python3 mathtools.py solve -a A -b B -c C
либо:   python3 mathtools.py solve  (коэффициенты вводятся с клавиатуры)

--------------------------------------------------------------------------------
 №  |   A   |  B  |  C  | Ожидаемый результат
--------------------------------------------------------------------------------
  1 |     1 |  -3 |   2 | Квадратное; D = 1; x1 = 1.000; x2 = 2.000; код 0
  2 |     1 |  -2 |   1 | Квадратное; D = 0; x = 1.000; код 0
  3 |     1 |   0 |   5 | Квадратное; D = -20; действительных корней нет; код 0
  4 |     0 |   2 |  -4 | Линейное; x = 2.000; код 0
  5 |     0 |   0 |   0 | Не уравнение: неизвестного нет; код 1
  6 |     0 |   0 |   7 | Не уравнение: неизвестного нет; код 1
  7 |   abc |   1 |   1 | Сообщение об ошибке: не целое число; код 1
  8 | 50000 |   1 |   1 | Сообщение об ошибке: вне диапазона; код 1
--------------------------------------------------------------------------------
  9 |    -1 |   3 |  -2 | Квадратное; D = 1; x1 = 2.000; x2 = 1.000; код 0
 10 |     2 |   0 |  -8 | Квадратное; D = 64; x1 = -2.000; x2 = 2.000; код 0
 11 |     1 |   0 |   0 | Квадратное; D = 0; x = 0.000; код 0
 12 |     0 |  -3 |   0 | Линейное; x = 0.000; код 0
 13 |     0 |   4 |   1 | Линейное; x = -0.250; код 0
 14 | 10000 | 10000 | 10000 | Квадратное; D = -300000000; корней нет; код 0
 15 |-10000 |   1 |   1 | Квадратное; D = 40001; x1 = 0.010; x2 = -0.010; код 0
 16 | 10001 |   1 |   1 | Сообщение об ошибке: вне диапазона; код 1
 17 |     1 |   1 |-10001 | Сообщение об ошибке: вне диапазона; код 1

--------------------------------------------------------------------------------

Пояснения к отдельным тестам:
  1  — квадратное уравнение с двумя корнями (обязательный случай);
  2  — квадратное уравнение с одним корнем (D = 0);
  3  — квадратное уравнение без действительных корней (D < 0);
  4  — линейное уравнение с одним корнем;
  5,6 — A = 0 и B = 0: неизвестное отсутствует при любом C;
  7,18,19 — исходные данные не являются целыми числами;
  8,16,17 — исходные данные выходят за допустимый диапазон |x| <= 10000;
  9  — отрицательный старший коэффициент, порядок вывода корней;
  14,15 — граничные значения диапазона.

=====================================================================
2. ТЕСТЫ КОМАНДНОЙ СТРОКИ
=====================================================================
Формат: команда запуска -> ожидаемый результат

 20. python3 mathtools.py
     -> справка по использованию в стандартный вывод; код возврата 0

 21. python3 mathtools.py --help
     -> справка по использованию в стандартный вывод; код возврата 0

 22. python3 mathtools.py help
     -> ОШИБКА: неизвестная команда (stderr); код возврата 1

 23. python3 mathtools.py SOLVE
     -> ОШИБКА: неизвестная команда (stderr); код возврата 1
        (команда чувствительна к регистру)

 24. python3 mathtools.py solve -a 1 -b 2
     -> ОШИБКА: неизвестный набор параметров (stderr); код возврата 1
        (пропущен параметр -c)

 25. python3 mathtools.py solve -a 1 -b 2 -c 3 -d 4
     -> ОШИБКА: неизвестный набор параметров (stderr); код возврата 1
        (лишний параметр)

 26. python3 mathtools.py solve -a 1 -b 2 -x 3
     -> ОШИБКА: неизвестный параметр (stderr); код возврата 1

 27. python3 mathtools.py solve -a 1 -c 3 -b 2
     -> ОШИБКА: неизвестный параметр (stderr); код возврата 1
        (параметры ожидаются в порядке -a -b -c)

 28. python3 mathtools.py solve 1 2 3
     -> ОШИБКА: неизвестный набор параметров (stderr); код возврата 1

=====================================================================
3. ОБЩИЕ ТРЕБОВАНИЯ
=====================================================================
  - при любой ошибке во входных данных код возврата ненулевой (1),
    а сообщение об ошибке выводится в стандартный поток ошибок (stderr);
  - при успешном решении код возврата нулевой (0),
    а результат выводится в стандартный поток вывода (stdout);
  - оба способа задания коэффициентов (параметры командной строки
    и ввод с клавиатуры) должны давать одинаковый результат:
    каждый тест 1-19 проверяется обоими способами.
